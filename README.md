# 📊 Data Analyst App

A modern and user-friendly **Data Analyst Web Application** that helps users upload datasets, clean data, perform Exploratory Data Analysis (EDA), generate visualizations, and understand important patterns and insights from their data.

## 🚀 Features

### 📁 Dataset Upload

* Upload CSV files
* Upload Excel files
* Preview uploaded data
* Display rows and columns
* Detect dataset structure automatically

### 🧹 Data Cleaning

* Detect missing values
* Identify duplicate records
* Check data types
* Handle missing values
* Remove duplicate rows
* Prepare clean datasets for analysis

### 📊 Exploratory Data Analysis

The application provides useful statistical information including:

* Dataset shape
* Column information
* Descriptive statistics
* Unique values
* Missing-value analysis
* Numerical and categorical column analysis

### 📈 Data Visualization

Generate different types of charts:

* Bar Chart
* Line Chart
* Pie Chart
* Histogram
* Scatter Plot
* Correlation Heatmap

These visualizations help identify:

* Trends
* Patterns
* Relationships
* Distributions
* Outliers

### 💡 Data Insights

The application helps users understand their datasets by highlighting important patterns and analytical findings.

### 📥 Cleaned Dataset

After data cleaning, users can download the processed dataset for further analysis.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/solankisumiksha-bit/Data-Analyst-app.git
```

### 2. Open the Project

```bash
cd Data-Analyst-app
```

### 3. Create a Virtual Environment

Windows:

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
python app.py
```

### 6. Open in Browser

Open:

```text
http://127.0.0.1:5000
```
